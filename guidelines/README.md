# Konstruktionsrichtlinien

Hier die eigenen Regeln als Markdown-Dateien ablegen (z.B. `wandstaerken.md`, `toleranzen.md`, `fusion-workflow.md`).
Der Connector in `connector/server.py` liefert sie an Claude aus.

Beispiele für Inhalte: Mindestwandstärke je Fertigungsverfahren, Passungen, Einheiten, Namensschema für Bauteile und Parameter.
